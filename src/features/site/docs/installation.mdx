# Installation

This guide will walk you through setting up Takeout for local development, from prerequisites to running your first development server.

## Prerequisites

Before installing Takeout, ensure you have the following tools installed on your system:

### Required

- **Node.js 24.3.0** - Takeout requires this specific version
- **Bun 1.2.23+** - Fast JavaScript runtime and package manager
- **Git** - Version control system
- **Docker Desktop** - For running PostgreSQL and other backend services

### Optional but Recommended

- **VS Code** or your preferred code editor
- **TablePlus** or another PostgreSQL client for database management
- **Xcode 15+** (macOS only) - For iOS development
- **Android Studio** - For Android development

## Installing Prerequisites

### Node.js and Bun

The easiest way to install Node.js is using a version manager:

```bash
# Install nvm (Node Version Manager)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# Install the required Node.js version
nvm install 24.3.0
nvm use 24.3.0
```

Then install Bun:

```bash
curl -fsSL https://bun.sh/install | bash
```

### Docker Desktop

Download and install Docker Desktop from [docker.com](https://www.docker.com/products/docker-desktop/).

## Quick Installation

The fastest way to get started is using the onboarding wizard:

```bash
git clone https://github.com/usetakeout/takeout3.git
cd takeout3
bun install
bun onboard
```

The onboarding wizard will:
- Verify all prerequisites are installed
- Set up your environment variables
- Initialize the database
- Configure GitHub OAuth (optional)
- Guide you through deployment setup (optional)

## Manual Installation

If you prefer to set up everything manually:

### 1. Clone and Install Dependencies

```bash
git clone https://github.com/usetakeout/takeout3.git
cd takeout3
bun install
```

The postinstall script will automatically:
- Build initial packages
- Bootstrap the project
- Apply One.js patches

### 2. Set Up Environment Variables

Copy the development environment template:

```bash
cp .env.development .env
```

Update `.env` with your configuration. At minimum, you'll need:

```bash
BETTER_AUTH_SECRET=your-secret-here
BETTER_AUTH_URL=http://localhost:8081
ONE_SERVER_URL=http://localhost:8081
```

Generate a secure auth secret:

```bash
openssl rand -hex 32
```

### 3. Start Backend Services

Start PostgreSQL and other services using Docker Compose:

```bash
bun backend
```

This will start:
- PostgreSQL on port 5433
- MinIO (S3-compatible storage) on port 9200
- Adminer (database UI) on port 8080

### 4. Run Database Migrations

In a new terminal, run the migrations:

```bash
bun migrate
```

This will:
- Create all necessary database tables
- Set up the Zero sync schema
- Run Better Auth migrations

### 5. Start the Development Server

```bash
bun dev
```

Your app will be available at:
- Web: http://localhost:8081
- API: http://localhost:8081/api
- Zero sync: http://localhost:4848

## IDE Setup

### VS Code

Install these recommended extensions:

```bash
code --install-extension biomejs.biome
code --install-extension bradlc.vscode-tailwindcss
code --install-extension esbenp.prettier-vscode
```

Create `.vscode/settings.json`:

```json
{
  "editor.defaultFormatter": "biomejs.biome",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "quickfix.biome": "explicit",
    "source.organizeImports.biome": "explicit"
  },
  "typescript.tsdk": "node_modules/typescript/lib"
}
```

### TypeScript Settings

The project uses TypeScript 5.8.3 with strict mode enabled. Type checking runs automatically with:

```bash
bun tko check types
```

Or in watch mode:

```bash
bun watch:types
```

## Mobile Development Setup

### iOS (macOS only)

1. Install Xcode 15+ from the App Store
2. Install Xcode Command Line Tools:

```bash
xcode-select --install
```

3. Install CocoaPods:

```bash
sudo gem install cocoapods
```

4. Run the iOS app:

```bash
bun ios
```

### Android

1. Download and install [Android Studio](https://developer.android.com/studio)
2. Install Android SDK 34+ through Android Studio
3. Set up environment variables in `~/.zshrc` or `~/.bashrc`:

```bash
export ANDROID_HOME=$HOME/Library/Android/sdk
export PATH=$PATH:$ANDROID_HOME/emulator
export PATH=$PATH:$ANDROID_HOME/platform-tools
```

4. Create an Android Virtual Device (AVD) in Android Studio
5. Run the Android app:

```bash
bun android
```

## Desktop Development Setup

### Tauri (macOS, Linux, Windows)

Install Rust and Tauri dependencies:

```bash
# Install Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# macOS additional dependencies
brew install pkg-config
```

Build and run the desktop app:

```bash
bun tko tauri dev
```

## Verification

Verify your installation is working correctly:

```bash
# Check all dependencies
bun tko check

# Run type checking
bun tko check types

# Run linter
bun lint:fix

# Run tests
bun test:unit
```

## Troubleshooting

### Node Version Mismatch

If you see errors about Node versions, ensure you're using the exact version specified in `package.json`:

```bash
node --version  # Should output v24.3.0
```

### Port Already in Use

If port 8081 is already in use:

```bash
# Find and kill the process
lsof -ti:8081 | xargs kill -9
```

### Docker Services Not Starting

If Docker services fail to start:

```bash
# Clean up old containers and volumes
bun backend:clean

# Restart services
bun backend
```

### Database Connection Issues

Ensure PostgreSQL is running and accessible:

```bash
# Test connection
psql postgresql://user:password@127.0.0.1:5433/postgres
```
