# Scripts Reference

Complete reference of all scripts available in the TKO CLI.

## Built-in Commands

### onboard
Setup wizard for new projects

```bash
bun tko onboard
```

### docs
View documentation

```bash
bun tko docs
bun tko docs list
```

### env:setup
Setup environment variables

```bash
bun tko env:setup
```

### run
Run multiple scripts in parallel

```bash
bun tko run script1 script2 script3
```

## Check Scripts

### check/dependencies
Check for circular dependencies

```bash
bun tko check dependencies
```

### check/lint
Run Biome linter

```bash
bun tko check lint
# or
bun lint
```

### check/types
Run TypeScript type checking

```bash
bun tko check types
```

## CI Scripts

### ci/release
Run full CI/CD pipeline with tests, builds, and deployment

```bash
bun tko ci release
```

### ci/backend
Start backend services for CI

```bash
bun tko ci backend
```

### ci/check
Run all CI checks

```bash
bun tko ci check
```

## Database Scripts

### db/add-migration
Add a new database migration

```bash
bun tko db add-migration migration-name
# or
bun db:migrate-add migration-name
```

### db/generate-drizzle
Generate Drizzle schema types

```bash
bun tko db generate-drizzle
# or
bun tko db generate
```

### db/migrate-drizzle
Run database migrations

```bash
bun tko db migrate-drizzle
# or
bun migrate
```

## Common Script Patterns

### Running Multiple Scripts

```bash
# Run in parallel
bun tko run script1 script2 script3

# Run sequentially
bun script1 && bun script2 && bun script3
```

### With Environment

```bash
# Development
bun run:dev bun tko script-name

# Production
bun run:prod bun tko script-name
```
