# Takeout

Takeout is a starter template for a real, cross-platform app. Auth and public
profiles are wired up, with data synced live between web and iOS through Zero
and one native SQLite application database.

## What's in the box

- **Auth** — email and password via better-auth, with a built-in
  "Login as Demo User" button for fast first runs.
- **Live data** — Zero + Drizzle keep clients and the server in sync without
  hand-rolled sockets.
- **Cross-platform UI** — Tamagui for design tokens, animations, and
  responsive layouts that compile down to both web and native React Native.
- **Public surface:** a landing page (the one you're hitting right now) and
  docs compiled to HAST during the production build.

## When to pick this template

Pick **Takeout** if you want a real product app to evolve from — auth and
data are wired so you can focus on what makes your app yours.

If you only need a marketing site or static blog, the **Static Site**
template is leaner.
