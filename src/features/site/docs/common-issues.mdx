# Common Issues

Quick solutions to specific error messages you might encounter.

## Error Messages

### "Cannot find module '~/...'"

**Error:**
```
Error: Cannot find module '~/features/auth'
```

**Cause:** TypeScript can't resolve path alias

**Solution:**
1. Restart TypeScript server (VS Code: Cmd+Shift+P → "TypeScript: Restart TS Server")
2. Check `tsconfig.json` has correct paths
3. Clear cache: `rm -rf node_modules/.vite && bun dev`

---

### "listen EADDRINUSE :::8081"

**Error:**
```
Error: listen EADDRINUSE: address already in use :::8081
```

**Cause:** Port 8081 is already in use

**Solution:**
```bash
lsof -ti:8081 | xargs kill -9
bun dev
```

---

### "Connection to database failed"

**Error:**
```
Error: Connection to database failed
```

**Cause:** PostgreSQL not running or wrong connection string

**Solution:**
```bash
# Check if running
docker compose ps

# Restart backend
bun backend:clean
bun backend
```

---

### "JavaScript heap out of memory"

**Error:**
```
FATAL ERROR: Reached heap limit Allocation failed - JavaScript heap out of memory
```

**Cause:** Node ran out of memory during build

**Solution:**
```bash
export NODE_OPTIONS="--max-old-space-size=4096"
bun tko web build
```

---

### "Missing BETTER_AUTH_SECRET"

**Error:**
```
Error: Missing BETTER_AUTH_SECRET
```

**Cause:** Environment variable not set

**Solution:**
```bash
# Generate secret
openssl rand -hex 32

# Add to .env
echo "BETTER_AUTH_SECRET=your-generated-secret" >> .env

# Restart dev server
bun dev
```

---

### "Cannot read property 'id' of null"

**Error:**
```
TypeError: Cannot read property 'id' of null
```

**Cause:** Accessing property on null/undefined object

**Solution:**
Add null checks:

```typescript
// Bad
const userId = user.id

// Good
const userId = user?.id
if (!userId) return null
```

---

### "Circular dependency detected"

**Error:**
```
Circular dependency detected: A → B → A
```

**Cause:** Files importing each other

**Solution:**
1. Check dependency chain:

```bash
bun tko check dependencies
```

2. Refactor to remove circular imports:
   - Move shared types to separate file
   - Use type-only imports: `import type { ... }`
   - Reorganize code structure

---

### "Pod install failed"

**Error:**
```
[!] Pod install failed
```

**Cause:** iOS dependencies issue

**Solution:**
```bash
cd ios
rm -rf Pods Podfile.lock
pod install --repo-update
```

### "Expected version 24.3.0, got 20.x.x"

**Error:**
```
Error: Expected Node version 24.3.0, got 20.x.x
```

**Cause:** Wrong Node version

---

### "Migration failed"

**Error:**
```
Error: Migration failed at step XXX
```

**Cause:** Invalid SQL in migration

**Solution:**
1. Check migration file syntax
2. Reset database (dev only):

```bash
bun backend:clean
bun backend
bun migrate
```

---

### "Rate limit exceeded"

**Error:**
```
Error: Rate limit exceeded for mutations
```

**Cause:** Too many mutations too quickly

**Solution:**
- Check for infinite loops in mutation code
- Implement debouncing for user actions
- Increase rate limit in Zero config (production only)

---

### "AWS credentials not found"


**Cause:** AWS CLI not configured

**Solution:**

```bash
aws configure --profile tamagui-dev
```

---

### "SSL certificate verification failed"

**Error:**
```
Error: certificate has expired
```

**Cause:** SSL certificate issue

**Solution:**
```bash
# Update certificates (macOS)
brew install curl

# Or disable SSL verification temporarily (not recommended)
NODE_TLS_REJECT_UNAUTHORIZED=0 bun dev
```

---

### "Docker daemon not running"

**Error:**
```
Error: Cannot connect to the Docker daemon
```

**Cause:** Docker Desktop not running

**Solution:**
1. Start Docker Desktop
2. Wait for it to fully start
3. Try command again

## Quick Diagnostics

Run these commands to diagnose issues:

```bash
# Check versions
node --version
bun --version
docker --version

# Check services
docker compose ps
lsof -i :8081
lsof -i :4848

# Check environment
cat .env | grep -v "SECRET"

# Check database
psql $ZERO_UPSTREAM_DB -c "SELECT 1"

# Check types
bun tko check types

# Check dependencies
bun tko check dependencies
```
