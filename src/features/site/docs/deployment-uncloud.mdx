# Uncloud Deployment

Deploy Takeout to Uncloud for a simplified deployment experience without managing AWS directly.

## Overview

Uncloud provides:
- Simplified deployment process
- Managed PostgreSQL with logical replication
- Automatic SSL certificates
- Built-in load balancing
- Easy scaling

## Prerequisites

- Uncloud account
- Docker installed locally
- Domain name (optional)

## Initial Setup

### 1. Install Uncloud CLI

```bash
npm install -g uncloud-cli

# Login
uncloud login
```

### 2. Create Project

```bash
uncloud init your-app-name
```

### 3. Configure Environment

Create `.env.production`:

```bash
BETTER_AUTH_SECRET=<your-secret>
BETTER_AUTH_URL=https://your-app.uncloud.app
ONE_SERVER_URL=https://your-app.uncloud.app
```

## Deployment

### Build and Deploy

```bash
# Deploy to production
bun tko uncloud deploy
```

This will:
1. Build Docker image
2. Push to Uncloud registry
3. Deploy services
4. Run database migrations
5. Configure load balancer

### Deploy to Staging

```bash
# Deploy to staging environment
bun tko uncloud deploy --env staging
```

## Configuration

### Scaling

Configure in `uncloud.config.ts`:

```typescript
export default {
  services: {
    webapp: {
      instances: { min: 1, max: 5 },
      resources: {
        cpu: '2 vCPU',
        memory: '4 GB',
      },
    },
    zero: {
      instances: { min: 1, max: 3 },
      resources: {
        cpu: '4 vCPU',
        memory: '8 GB',
      },
    },
  },
}
```

### Database

Uncloud provides managed PostgreSQL:

```typescript
database: {
  postgres: {
    version: '16',
    storage: '20 GB',
    backups: {
      retention: 7,
      schedule: '0 3 * * *',
    },
  },
}
```

## Monitoring

### View Logs

```bash
# All logs
bun tko uncloud logs

# Specific service
bun tko uncloud logs webapp

# Follow logs
bun tko uncloud logs --follow
```

### Metrics

View metrics in Uncloud dashboard:
- Request rate
- Response time
- Error rate
- Resource usage

## Custom Domains

### Add Domain

```bash
uncloud domains add yourdomain.com
```

### Configure DNS

Point your domain to Uncloud:

```
CNAME yourdomain.com -> your-app.uncloud.app
```

SSL certificate is automatically provisioned.
