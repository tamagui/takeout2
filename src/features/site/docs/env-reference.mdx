# Environment Variables Reference

Complete reference of all environment variables available in Takeout.

## Authentication

### BETTER_AUTH_SECRET
- **Type:** String (required)
- **Purpose:** Secret for session encryption
- **Example:** `openssl rand -hex 32`
- **Development:** Can use placeholder
- **Production:** Must be cryptographically secure

### BETTER_AUTH_URL
- **Type:** URL (required)
- **Purpose:** Base URL for authentication callbacks
- **Development:** `http://localhost:8081`
- **Production:** `https://yourdomain.com`

## Server

### ONE_SERVER_URL
- **Type:** URL (required)
- **Purpose:** Server base URL for API routes
- **Development:** `http://localhost:8081`
- **Production:** `https://yourdomain.com`

### ONE_SUSPEND_ROUTES
- **Type:** Boolean (optional)
- **Purpose:** Enable route suspense (development only)
- **Development:** `1`
- **Production:** Not set

## Database

### ZERO_UPSTREAM_DB
- **Type:** PostgreSQL connection string (required)
- **Purpose:** Main PostgreSQL database
- **Development:** `postgresql://user:password@127.0.0.1:5433/postgres`
- **Production:** Auto-configured by SST

### ZERO_CVR_DB
- **Type:** PostgreSQL connection string (required)
- **Purpose:** Zero Client View Record database
- **Development:** `postgresql://user:password@127.0.0.1:5433/zero_cvr`
- **Production:** Auto-configured by SST

### ZERO_CHANGE_DB
- **Type:** PostgreSQL connection string (required)
- **Purpose:** Zero change tracking database
- **Development:** `postgresql://user:password@127.0.0.1:5433/zero_cdb`
- **Production:** Auto-configured by SST

### ZERO_AUTH_JWKS_URL
- **Type:** URL (required)
- **Purpose:** JWT key set URL for Zero authentication
- **Development:** `http://localhost:8081/api/auth/jwks`
- **Production:** `https://yourdomain.com/api/auth/jwks`

### ZERO_PUSH_URL
- **Type:** URL (required)
- **Purpose:** Zero mutation endpoint
- **Development:** `http://localhost:8081/api/zero/push`
- **Production:** `https://yourdomain.com/api/zero/push`

### ZERO_GET_QUERIES_URL
- **Type:** URL (required)
- **Purpose:** Zero query endpoint
- **Development:** `http://localhost:8081/api/zero/pull`
- **Production:** `https://yourdomain.com/api/zero/pull`

### ZERO_REPLICA_FILE
- **Type:** File path (required)
- **Purpose:** Local SQLite replica file location
- **Development:** `/tmp/onechat_replica.db`
- **Production:** `sync-replica.db`

## Client Variables

### VITE_PUBLIC_ZERO_SERVER
- **Type:** URL (required, client-side)
- **Purpose:** Zero server WebSocket URL
- **Development:** `http://localhost:4848`
- **Production:** `https://zero.yourdomain.com`

### VITE_POSTHOG_API_KEY
- **Type:** String (optional, client-side)
- **Purpose:** PostHog analytics API key
- **Development:** Empty or dev key
- **Production:** Production API key

### VITE_POSTHOG_HOST
- **Type:** URL (optional, client-side)
- **Purpose:** PostHog server URL
- **Development:** `https://app.posthog.com`
- **Production:** `https://app.posthog.com`

## Storage

### CLOUDFLARE_R2_ENDPOINT
- **Type:** URL (required)
- **Purpose:** R2 S3-compatible API endpoint
- **Development:** `http://localhost:9200/chat` (MinIO)
- **Production:** `https://account.r2.cloudflarestorage.com`

### CLOUDFLARE_R2_ACCESS_KEY
- **Type:** String (required)
- **Purpose:** R2 access key ID
- **Development:** `minio`
- **Production:** Your R2 access key

### CLOUDFLARE_R2_SECRET_KEY
- **Type:** String (required)
- **Purpose:** R2 secret access key
- **Development:** `minio_password`
- **Production:** Your R2 secret key

### CLOUDFLARE_R2_PUBLIC_URL
- **Type:** URL (required)
- **Purpose:** Public URL for uploaded files
- **Development:** `http://localhost:9200/chat`
- **Production:** `https://your-bucket.r2.dev`

## Email

### POSTMARK_SERVER_TOKEN
- **Type:** String (required)
- **Purpose:** Postmark API token for sending emails
- **Development:** Sandbox token
- **Production:** Production token

## OAuth Providers

### GITHUB_CLIENT_ID
- **Type:** String (optional)
- **Purpose:** GitHub OAuth application client ID
- **Setup:** Create at https://github.com/settings/developers

### GITHUB_CLIENT_SECRET
- **Type:** String (optional)
- **Purpose:** GitHub OAuth application secret

### GOOGLE_CLIENT_ID
- **Type:** String (optional)
- **Purpose:** Google OAuth client ID
- **Setup:** Create at https://console.cloud.google.com

### GOOGLE_CLIENT_SECRET
- **Type:** String (optional)
- **Purpose:** Google OAuth client secret

## Apple Push Notifications

### APNS_ENDPOINT
- **Type:** URL (optional)
- **Purpose:** Apple Push Notification service endpoint
- **Development:** `https://api.sandbox.push.apple.com`
- **Production:** `https://api.push.apple.com`

### APNS_TEAM_ID
- **Type:** String (optional)
- **Purpose:** Apple Developer Team ID

### APNS_KEY_ID
- **Type:** String (optional)
- **Purpose:** APNs authentication key ID

### APNS_KEY
- **Type:** String (optional)
- **Purpose:** APNs private key (Base64 encoded)

## AWS

### AWS_ACCESS_KEY_ID
- **Type:** String (required for deployment)
- **Purpose:** AWS access key for deployment

### AWS_SECRET_ACCESS_KEY
- **Type:** String (required for deployment)
- **Purpose:** AWS secret key for deployment

## Development Only

### NODE_ENV
- **Type:** String
- **Values:** `development`, `production`, `test`
- **Purpose:** Node environment mode

### DEBUG
- **Type:** Boolean (optional)
- **Purpose:** Enable debug logging
- **Development:** `true`
- **Production:** `false`

## Generated Variables

These are auto-set by SST during deployment:

### GIT_SHA
- **Purpose:** Git commit SHA for deployment tracking
- **Auto-set:** Yes

### NODE_OPTIONS
- **Purpose:** Node.js runtime options
- **Example:** `--max-old-space-size=6144`
- **Auto-set:** Yes in production

## Security Notes

### Never Commit

Never commit these to git:
- `BETTER_AUTH_SECRET` (production)
- `AWS_ACCESS_KEY_ID`
- `AWS_SECRET_ACCESS_KEY`
- `CLOUDFLARE_R2_SECRET_KEY`
- `POSTMARK_SERVER_TOKEN` (production)
- OAuth secrets
- APNS keys

### Client Variables Warning

Variables prefixed with `VITE_` are exposed to clients. Never put secrets in `VITE_` variables.

## Validation

All required variables are validated on startup. Missing variables cause immediate failure with clear error messages.
