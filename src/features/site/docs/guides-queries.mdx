# Guide: Writing Zero Queries

This guide teaches you how to write effective Zero queries for fetching and subscribing to real-time data.

## Basic Query Structure

Zero queries run against your local SQLite database and automatically stay in sync with the server.

```typescript
import { useQuery } from '~/zero'

const [posts] = useQuery(z.posts.orderBy('createdAt', 'desc'))
```

## Query Methods

### Filtering with where()

```typescript
// Single condition
const [userPosts] = useQuery(
  z.posts.where('userId', userId)
)

// Multiple conditions (AND)
const [recentPosts] = useQuery(
  z.posts
    .where('userId', userId)
    .where('published', true)
)

// Comparison operators
const [newPosts] = useQuery(
  z.posts.where('createdAt', '>', Date.now() - 86400000)
)
```

### Ordering with orderBy()

```typescript
// Descending order
const [posts] = useQuery(
  z.posts.orderBy('createdAt', 'desc')
)

// Ascending order
const [posts] = useQuery(
  z.posts.orderBy('title', 'asc')
)

// Multiple order fields
const [posts] = useQuery(
  z.posts
    .orderBy('priority', 'desc')
    .orderBy('createdAt', 'desc')
)
```

### Limiting with limit()

```typescript
// First 10 results
const [posts] = useQuery(
  z.posts
    .orderBy('createdAt', 'desc')
    .limit(10)
)
```

### Relationships with related()

```typescript
// One-to-one relationship
const [postsWithUsers] = useQuery(
  z.posts
    .related('user', (q) => q.one('userId', 'users', 'id'))
    .orderBy('createdAt', 'desc')
)

// Access related data
postsWithUsers.forEach(post => {
  console.info(post.title)
  console.info(post.user.name) // Related user
})

// One-to-many relationship
const [usersWithPosts] = useQuery(
  z.users
    .related('posts', (q) => q.many('id', 'posts', 'userId'))
)

usersWithPosts.forEach(user => {
  console.info(user.name)
  console.info(user.posts.length) // Related posts
})
```

## Query Patterns

### Organized Queries

Create query objects for reusability:

```typescript
// src/features/posts/queries.ts
export const postsQueries = {
  all: () =>
    z.posts.orderBy('createdAt', 'desc'),

  byUser: (userId: string) =>
    z.posts
      .where('userId', userId)
      .orderBy('createdAt', 'desc'),

  byId: (id: string) =>
    z.posts.where('id', id),

  recent: (limit = 10) =>
    z.posts
      .orderBy('createdAt', 'desc')
      .limit(limit),

  published: () =>
    z.posts
      .where('published', true)
      .orderBy('createdAt', 'desc'),

  withUser: () =>
    z.posts
      .related('user', (q) => q.one('userId', 'users', 'id'))
      .orderBy('createdAt', 'desc'),
}
```

Use in components:

```typescript
import { postsQueries } from '~/features/posts/queries'

export function PostsList() {
  const [posts] = useQuery(postsQueries.all())
  return <PostList posts={posts} />
}

export function UserPosts({ userId }) {
  const [posts] = useQuery(postsQueries.byUser(userId))
  return <PostList posts={posts} />
}
```

### Conditional Queries

Query based on conditions:

```typescript
export function PostsList({ userId, showAll }) {
  const [posts] = useQuery(
    showAll
      ? z.posts.orderBy('createdAt', 'desc')
      : z.posts.where('userId', userId).orderBy('createdAt', 'desc')
  )

  return <PostList posts={posts} />
}
```

### Paginated Queries

Implement pagination:

```typescript
export function PaginatedPosts() {
  const [page, setPage] = useState(1)
  const pageSize = 20

  const [posts] = useQuery(
    z.posts
      .orderBy('createdAt', 'desc')
      .limit(page * pageSize)
  )

  const loadMore = () => setPage(p => p + 1)

  return (
    <>
      <PostList posts={posts} />
      <Button onPress={loadMore}>Load More</Button>
    </>
  )
}
```

## Performance Optimization

### Limit Results

Always limit query results:

```typescript
// Bad - loads everything
const [posts] = useQuery(z.posts)

// Good - loads first 20
const [posts] = useQuery(z.posts.limit(20))
```

### Use Indexes

Add indexes for filtered fields:

```typescript
// schema-public.ts
export const posts = pgTable('posts', {
  userId: text('user_id').notNull(),
  createdAt: bigint('created_at', { mode: 'number' }).notNull(),
}, (table) => ({
  userIdIdx: index('posts_user_id_idx').on(table.userId),
  createdAtIdx: index('posts_created_at_idx').on(table.createdAt),
}))
```

### Query Memoization

Zero automatically memoizes identical queries:

```typescript
// Both components share same query subscription
function ComponentA() {
  const [posts] = useQuery(z.posts.limit(10))
}

function ComponentB() {
  const [posts] = useQuery(z.posts.limit(10))
}
```

## Advanced Patterns

### Computed Values

Transform query results:

```typescript
export function PostsWithAge() {
  const [posts] = useQuery(z.posts.orderBy('createdAt', 'desc'))

  const postsWithAge = posts.map(post => ({
    ...post,
    age: Date.now() - post.createdAt,
    isNew: Date.now() - post.createdAt < 86400000,
  }))

  return <PostList posts={postsWithAge} />
}
```

### Filtered Views

Client-side filtering for complex logic:

```typescript
export function FilteredPosts({ userId, search }) {
  const [posts] = useQuery(z.posts.where('userId', userId))

  const filtered = posts.filter(post =>
    post.title.toLowerCase().includes(search.toLowerCase())
  )

  return <PostList posts={filtered} />
}
```

### Aggregations

Compute aggregations client-side:

```typescript
export function PostStats({ userId }) {
  const [posts] = useQuery(z.posts.where('userId', userId))

  const stats = {
    total: posts.length,
    published: posts.filter(p => p.published).length,
    drafts: posts.filter(p => !p.published).length,
    totalViews: posts.reduce((sum, p) => sum + p.views, 0),
  }

  return <StatsDisplay stats={stats} />
}
```

## Common Patterns

### Search

```typescript
export function PostSearch({ query }) {
  const [posts] = useQuery(z.posts)

  const results = posts.filter(post =>
    post.title.toLowerCase().includes(query.toLowerCase()) ||
    post.content.toLowerCase().includes(query.toLowerCase())
  )

  return <SearchResults results={results} />
}
```

### Filtering by Status

```typescript
export function PostsByStatus({ status }) {
  const [posts] = useQuery(
    z.posts
      .where('status', status)
      .orderBy('createdAt', 'desc')
  )

  return <PostList posts={posts} />
}
```

### User-Specific Data

```typescript
export function MyPosts() {
  const { user } = useAuth()

  const [posts] = useQuery(
    z.posts
      .where('userId', user.id)
      .orderBy('createdAt', 'desc')
  )

  return <PostList posts={posts} />
}
```
