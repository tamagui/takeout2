# Tech Stack

Takeout is built with carefully selected modern technologies that provide excellent developer experience, performance, and cross-platform capabilities.

## Core Framework

### One.js

**One.js** is a universal React framework that enables building web and native apps from a single codebase.

- **Version:** 1.2.6+
- **File-based routing** - Convention-based routing for web and mobile
- **Universal APIs** - Same code runs on web and native
- **SSR support** - Server-side rendering for better SEO
- **API routes** - Build backend endpoints alongside frontend

```typescript
// app/(tabs)/index.tsx - Automatically becomes a route
export function HomePage() {
  return <Text>Welcome to Takeout</Text>
}
```

Learn more: [onestack.dev](https://onestack.dev/)

### React 19

**React 19** provides cutting-edge features for building modern UIs.

- **Version:** 19.1.0
- **Concurrent rendering** - Better performance for complex UIs
- **Server components** - Reduced client bundle size
- **Automatic batching** - Optimized re-renders
- **Transitions** - Smooth UI state changes

```typescript
import { useTransition } from 'react'

const [isPending, startTransition] = useTransition()
```

## UI Framework

### Tamagui

**Tamagui** is a universal design system that works across web and native with excellent performance.

- **Version:** 1.136.1+
- **Cross-platform components** - Same API for web and native
- **Optimizing compiler** - Removes runtime overhead
- **Theme system** - Easy dark mode and customization
- **Animation support** - Integrated with Motion and Reanimated

```typescript
import { Button, YStack } from 'tamagui'

<YStack gap="$4" padding="$4">
  <Button onPress={() => console.info('Pressed')}>
    Click Me
  </Button>
</YStack>
```

**Component libraries:**
- `@tamagui/lucide-icons` - Icon set
- `@tamagui/toast` - Toast notifications
- `@tamagui/linear-gradient` - Gradients

Learn more: [tamagui.dev](https://tamagui.dev/)

### Animation

**React Native Reanimated** - Performant animations

- **Version:** 4.1.3+
- Runs on UI thread for 60fps
- Gesture support via `react-native-gesture-handler`
- Shared element transitions

```typescript
import Animated, { useAnimatedStyle } from 'react-native-reanimated'

const animatedStyle = useAnimatedStyle(() => ({
  transform: [{ scale: withSpring(isPressed ? 0.95 : 1) }]
}))
```

**Motion** - Web-optimized animations (alternative)

- **Version:** 12.23.22
- Declarative animations
- Layout animations
- Gesture support

## Data Layer

### Zero

**Zero** is a real-time sync engine that provides offline-first data synchronization.

- **Version:** 0.24.2025101500 (@rocicorp/zero)
- **Local-first architecture** - App works offline
- **Real-time sync** - Changes propagate instantly
- **Optimistic UI** - Immediate feedback
- **Conflict resolution** - Automatic merge of concurrent edits
- **TypeScript support** - Full type safety

```typescript
import { useQuery } from '~/zero'

const [posts] = useQuery(z.posts.orderBy('createdAt', 'desc'))
```

**over-zero** - Enhanced Zero utilities

- **Version:** 0.0.23
- Helper functions for common patterns
- Better TypeScript integration
- Development tools

Learn more: [zero.rocicorp.dev](https://zero.rocicorp.dev/)

### Drizzle ORM

**Drizzle ORM** provides type-safe database access with excellent DX.

- **Version:** 0.40.0+
- **Type-safe queries** - Catch errors at compile time
- **Schema migrations** - Automatic migration generation
- **PostgreSQL optimized** - Best-in-class PostgreSQL support
- **No code generation required** - Direct TypeScript inference

```typescript
import { db } from '~/database'
import { posts } from '~/database/schema-public'

const allPosts = await db.select().from(posts)
```

Learn more: [orm.drizzle.team](https://orm.drizzle.team/)

## Authentication

### Better Auth

**Better Auth** is a modern authentication library with excellent TypeScript support.

- **Version:** 1.3.32+
- **Multiple providers** - Email/password, OAuth, magic links
- **Session management** - Secure, encrypted sessions
- **JWKS support** - JWT key sets for Zero integration
- **TypeScript-first** - Fully typed API

```typescript
import { auth } from '~/features/auth/server/auth'

const session = await auth.api.getSession({ headers })
```

**better-fetch** - Companion HTTP client

- **Version:** 1.1.18
- Type-safe API calls
- Automatic retries
- Progress tracking

Learn more: [better-auth.com](https://www.better-auth.com/)

## Database

### PostgreSQL

**PostgreSQL** is the primary database, running via Aurora Serverless v2 in production.

- **Version:** 16.8
- **Logical replication** - Required for Zero sync
- **JSONB support** - Flexible data structures
- **Full-text search** - Built-in search capabilities
- **Aurora Serverless v2** - Auto-scaling in production

**Local development:**
- Runs in Docker via `docker-compose.yml`
- Port 5433 (to avoid conflicts with system PostgreSQL)
- Three databases: `postgres`, `zero_cvr`, `zero_cdb`

### SQLite (Client-side)

**@op-engineering/op-sqlite** - Fast SQLite for React Native

- **Version:** 15.0.7+
- Used by Zero for local storage
- Optimized for mobile performance
- Supports encryption

## Build Tools

### Bun

**Bun** is the primary JavaScript runtime and package manager.

- **Version:** 1.2.23+
- **Fast installs** - 10-100x faster than npm
- **Built-in bundler** - No webpack/rollup needed
- **TypeScript support** - Native .ts execution
- **Test runner** - Vitest compatibility

```bash
bun install    # Install dependencies
bun dev        # Run dev server
bun test       # Run tests
```

### Vite

**Vite** powers the web development and build pipeline.

- **Version:** 7.1.12+
- **Lightning fast HMR** - Instant hot module reload
- **Optimized builds** - Production-ready bundles
- **Plugin ecosystem** - Extensible architecture

### TypeScript

**TypeScript** provides static type checking across the entire stack.

- **Version:** 5.8.3
- **Strict mode** - Maximum type safety
- **tsgo compiler** - Fast incremental builds
- **Path aliases** - Clean imports with `~` alias

## Testing

### Vitest

**Vitest** is the unit testing framework.

- **Version:** 4.0.3+
- **Fast execution** - Powered by Vite
- **Jest compatible** - Familiar API
- **TypeScript support** - No additional config

```typescript
import { describe, it, expect } from 'vitest'

describe('MyComponent', () => {
  it('renders correctly', () => {
    expect(true).toBe(true)
  })
})
```

### Playwright

**Playwright** provides end-to-end testing.

- **Version:** 1.55.0+
- **Cross-browser** - Chromium, Firefox, WebKit
- **Reliable selectors** - Auto-waiting and retry
- **Screenshots and videos** - Debug test failures

```typescript
import { test, expect } from '@playwright/test'

test('login flow', async ({ page }) => {
  await page.goto('/')
  await page.click('text=Login')
  await expect(page).toHaveURL('/dashboard')
})
```

## Version Management

### Engine Requirements

```json
{
  "engines": {
    "node": "24.3.0",
    "npm": "10.8.3"
  },
  "packageManager": "bun@1.2.23"
}
```

The project automatically checks for correct Node version on startup.

### Dependency Updates

Use the TKO CLI for safe dependency updates:

```bash
# Update specific framework
bun tko upgrade one
bun tko upgrade tamagui
bun tko upgrade zero

# Update all deps (careful!)
bun upgrade
```
