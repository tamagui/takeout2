title: Agents
description: AI-powered development with Takeout
---

Takeout has had an immense amount development in setting up a great LLM coding
agent harness. It has **24** and counting specific skill docs, not to mention
repo-level docs throughout.

Going further, the scripting system is extensive, well organized, and well
documented, which we've found really helps agents find the right tool to use and
right ways to debug and solve problems.

The `over-zero` packages bring a Rails-like elegance to the structure of your
data, schema, mutations, and queries, which we find makes it so agents are
basically able to entirely solve features without much guidance beyond what you
want.

A complete test suite with integration tests that's easy to run, run via
`bun run ci --dry-run`, further lets them verify with certainty their changes
work all the way through to release.
