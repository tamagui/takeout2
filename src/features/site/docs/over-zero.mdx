[over-zero](https://github.com/tamagui/over-zero) provides queries, mutations, and permissions on top of [Zero](https://zero.rocicorp.dev). Full docs in `packages/over-zero/readme.md`.

## Quick overview

**Queries** - plain functions using `zql` builder, auto-wrapped with validators:

```ts
import { zql, where } from 'over-zero'

const permission = where('post', (q, auth) => q.cmp('userId', auth?.id || ''))

export const allPosts = (props: { limit?: number }) => {
  return zql.post.where(permission).orderBy('createdAt', 'desc').limit(props.limit || 20)
}
```

**Mutations** - schema + permissions + custom mutations together:

```ts
import { table, mutations, where } from 'over-zero'

export const schema = table('post').columns({ id: string(), content: string(), userId: string() }).primaryKey('id')
export const permissions = where('post', (q, auth) => q.cmp('userId', auth?.id || ''))
export const mutate = mutations(schema, permissions, {
  // custom mutations here, CRUD auto-generated
})
```

**Permissions** - `where()` helpers, server-side only, auto-pass on client.

## Key rules

- Mutations run on both client and server - must be deterministic
- Pass `id` and timestamps from client, don't generate inside mutations
- Use `asyncTasks` for side effects (runs after transaction commits)

bun tko zero generate
