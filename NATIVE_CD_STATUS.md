## Android CD Implementation Details

The Android CD required several fixes for the VxRN/One framework's Metro bundling issues:

1. **Disk Space**: GitHub runners have limited space. Fixed by:
   - Removing dotnet, ndk, ghc, boost
   - Building only arm64-v8a architecture

2. **Metro Bundler Failure**: VxRN's Metro plugin doesn't work in CI. Fixed by:
   - Using `expo export:embed` to pre-bundle JS
   - Setting `debuggableVariants = ["debug", "release"]` when `SKIP_BUNDLING=1`
   - This prevents the createBundleReleaseJsAndAssets task from being created

3. **Dynamic build.gradle Patching**: Since android/ is gitignored (generated by prebuild), we patch build.gradle in CI:
   - Add `skipBundling` check
   - Configure `debuggableVariants` dynamically
   - Wrap vxrn task registration with skipBundling check
