## Prerequisites

- **Bun** 1.2+ - [bun.sh](https://bun.sh)
- **Docker** - must be running
- **Git**

For mobile: Xcode 15+ (iOS) or Android Studio with JDK 17+

## Setup

```bash
git clone https://github.com/usetakeout/takeout3.git my-app
cd my-app
bun install
bun onboard
```

Onboarding sets up environment, project name, and CI/CD config.

## Run

Two terminals:

```bash
bun backend   # postgres, zero, minio
bun dev       # vite dev server
```

Open [localhost:8081](http://localhost:8081).

## Mobile

```bash
bun ios       # simulator
bun android   # emulator
```

## What's running

`bun backend` starts via docker-compose:
- PostgreSQL on 5433
- Zero sync on 4848
- MinIO (S3) on 9000

`bun dev` starts:
- Vite with hot reload
- Background type checking
