Takeout includes both unit tests (Vitest) and integration tests (Playwright).

## Running tests

```bash
# all tests
bun test

# unit tests only
bun test:unit

# integration tests only
bun test:integration
```

## Unit tests

Unit tests use [Vitest](https://vitest.dev/) and live alongside source files:

```
src/
├── features/
│   └── feed/
│       ├── FeedList.tsx
│       └── FeedList.test.ts
```

### Writing unit tests

```ts
// src/features/feed/FeedList.test.ts
import { describe, it, expect } from 'vitest'
import { formatDate } from './utils'

describe('formatDate', () => {
  it('formats recent dates as relative', () => {
    const now = Date.now()
    expect(formatDate(now - 60000)).toBe('1m ago')
  })

  it('formats old dates as absolute', () => {
    const oldDate = new Date('2024-01-01')
    expect(formatDate(oldDate.getTime())).toBe('Jan 1, 2024')
  })
})
```

### Testing hooks

```ts
import { renderHook } from '@testing-library/react'
import { useComments } from './useComments'

describe('useComments', () => {
  it('returns empty array initially', () => {
    const { result } = renderHook(() => useComments('post-1'))
    expect(result.current()).toEqual([])
  })
})
```

### Mocking

```ts
import { vi } from 'vitest'

vi.mock('~/data/zero', () => ({
  zero: {
    mutate: {
      createPost: vi.fn(),
    },
  },
}))
```

## Integration tests

Integration tests use [Playwright](https://playwright.dev/) and test the full app:

```
src/test/
├── e2e/
│   ├── auth.spec.ts
│   └── feed.spec.ts
├── playwright.config.ts
└── vitest.config.ts
```

### Writing integration tests

```ts
// src/test/e2e/auth.spec.ts
import { test, expect } from '@playwright/test'

test('user can sign in', async ({ page }) => {
  await page.goto('/sign-in')

  await page.fill('[name="email"]', 'test@example.com')
  await page.fill('[name="password"]', 'password123')
  await page.click('button[type="submit"]')

  await expect(page).toHaveURL('/feed')
})
```

### Test fixtures

```ts
// src/test/fixtures.ts
import { test as base } from '@playwright/test'

export const test = base.extend({
  authenticatedPage: async ({ page }, use) => {
    // sign in before test
    await page.goto('/sign-in')
    await page.fill('[name="email"]', 'test@example.com')
    await page.fill('[name="password"]', 'password')
    await page.click('button[type="submit"]')
    await use(page)
  },
})
```

### Running specific tests

```bash
# run a specific test file
bun test:integration src/test/e2e/auth.spec.ts

# run tests matching a pattern
bun test:integration --grep "sign in"
```

## CI testing

Tests run automatically in CI:

```yaml
# .github/workflows/ci.yml
- name: Run tests
  run: bun test
```

The CI environment:
- Starts backend services in Docker
- Runs unit tests
- Builds the app
- Runs integration tests against production build

## Test configuration

### Vitest config

```ts
// src/test/vitest.config.ts
export default defineConfig({
  test: {
    environment: 'node',
    include: ['src/**/*.test.ts'],
  },
})
```

### Playwright config

```ts
// src/test/playwright.config.ts
export default defineConfig({
  testDir: './e2e',
  use: {
    baseURL: 'http://localhost:8081',
  },
})
```

## Best practices

1. **Test behavior, not implementation** - Focus on what the code does, not how
2. **Use descriptive names** - Test names should explain what's being tested
3. **Keep tests isolated** - Each test should be independent
4. **Mock external services** - Don't hit real APIs in unit tests
5. **Use integration tests for flows** - Test complete user journeys

## Debugging tests

### Unit tests

```bash
# run in watch mode
bun test:unit --watch

# run with verbose output
bun test:unit --reporter=verbose
```

### Integration tests

```bash
# run with browser visible
bun test:integration --headed

# debug mode (pauses on failure)
bun test:integration --debug
```
