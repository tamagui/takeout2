PostgreSQL with Drizzle ORM. Schema changes sync to Zero.

## Schema files

- `src/database/schema-public.ts` - synced to Zero (client-visible)
- `src/database/schema-private.ts` - server-only

```ts
// schema-public.ts
import { pgTable, text, timestamp } from 'drizzle-orm/pg-core'

export const post = pgTable('post', {
  id: text('id').primaryKey(),
  content: text('content').notNull(),
  authorId: text('author_id').references(() => user.id),
  createdAt: timestamp('created_at').defaultNow(),
})
```

## Migrations

```bash
bun migrate              # generate and apply
bun tko db generate      # generate only
bun db:migrate-add name  # one-off SQL migration
```

## Local database

Docker on port 5433:
```
postgresql://user:password@localhost:5433/postgres
```

Zero databases (auto-created):
- `postgres` - main app data
- `zero_cvr` - client view records
- `zero_cdb` - change log

## After schema changes

```bash
bun migrate
bun tko zero generate
```

## Relations

```ts
export const postRelations = relations(post, ({ one }) => ({
  author: one(user, {
    fields: [post.authorId],
    references: [user.id],
  }),
}))
```

## Tips

- Use text IDs (`randomId()`) - Zero works best with strings
- Add `createdAt`/`updatedAt` for sync ordering
- Public vs private - only expose what clients need
