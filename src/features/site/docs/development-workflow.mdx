This guide covers the typical development workflow when building with Takeout.

## Starting development

Open two terminal windows:

```bash
# terminal 1 - backend services
bun backend

# terminal 2 - dev server
bun dev
```

The backend starts PostgreSQL, Zero sync, and MinIO. The dev server starts Vite with hot reloading.

## Project structure

```
app/                    # routes
├── (tabs)/             # tab navigation (native)
├── (site)/             # marketing site (web)
└── api/                # API routes

src/
├── features/           # feature modules
│   ├── auth/           # authentication feature
│   ├── feed/           # feed feature
│   └── profile/        # profile feature
├── interface/          # shared UI components
├── data/               # Zero queries and mutations
├── database/           # schema and migrations
└── server/             # server utilities
```

## Adding a feature

1. Create a feature folder in `src/features/`:

```
src/features/comments/
├── CommentList.tsx
├── CommentForm.tsx
├── useComments.ts
└── index.ts
```

2. Add database schema if needed:

```ts
// src/database/schema-public.ts
export const comment = pgTable('comment', {
  id: text('id').primaryKey(),
  postId: text('post_id').references(() => post.id),
  content: text('content').notNull(),
  authorId: text('author_id').references(() => user.id),
  createdAt: timestamp('created_at').defaultNow(),
})
```

3. Run migrations:

```bash
bun migrate
bun tko zero generate
```

4. Create mutations in `src/data/mutations.ts`:

```ts
createComment: (ctx: MutatorContext, args: CreateCommentArgs) => {
  ctx.tx.comment.insert(args)
},
```

5. Create a query hook:

```ts
// src/features/comments/useComments.ts
export function useComments(postId: string) {
  return useQuery(
    zero.query.comment
      .where('postId', '=', postId)
      .orderBy('createdAt', 'asc')
  )
}
```

## Adding a route

### Tab route (native app)

Create a file in `app/(tabs)/`:

```tsx
// app/(tabs)/explore.tsx
export function ExplorePage() {
  return (
    <View>
      <Text>Explore</Text>
    </View>
  )
}
```

### Site route (marketing)

Create a file in `app/(site)/`:

```tsx
// app/(site)/about.tsx
export function AboutPage() {
  return (
    <Container>
      <H1>About</H1>
    </Container>
  )
}
```

### API route

Create a file in `app/api/`:

```ts
// app/api/webhook+api.ts
export async function POST(request: Request) {
  const body = await request.json()
  // handle webhook
  return Response.json({ ok: true })
}
```

## Code quality

### Linting

```bash
# check for issues
bun lint

# auto-fix issues
bun lint:fix
```

### Type checking

```bash
bun tko check types
```

### All checks

```bash
bun tko check
```

## Testing

### Unit tests

```bash
bun test:unit
```

### Integration tests

```bash
bun test:integration
```

### All tests

```bash
bun test
```

## Database changes

1. Modify schema in `src/database/schema-public.ts`
2. Run `bun migrate` (with backend running)
3. Run `bun tko zero generate` to update Zero types

## Mobile development

### iOS

```bash
bun ios
```

First run will build the native app. Subsequent runs use the dev server.

### Android

```bash
bun android
```

### Rebuilding native apps

After changing native dependencies in `app.config.ts`:

```bash
bun prebuild:native
bun ios  # or bun android
```

## Hot reloading

- **Web**: Automatic via Vite
- **Native**: Automatic for JS changes, rebuild needed for native changes

## Debugging

### Console logs

Use `console.info()` for debug output (not `console.log()`).

### Zero debugging

```tsx
// view local database
window.zero.db.exec('SELECT * FROM post')

// check sync status
const { syncing } = useZeroStatus()
```

### React DevTools

Install the browser extension for component inspection.
