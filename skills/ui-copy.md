# UI copy and voice

Copy conventions; the words themselves follow the brief's product voice:

- Empty states tell the user the next action, not just "nothing here yet".
- Never show a task term, action id, test id, or route segment as copy; an inline editor with its own Cancel keeps its opener's label.
- A field placeholder names the format or kind of entry ("Goal name", "0.00"), never a plausible value: gray example data such as a real name or amount reads as already filled in.
- Buttons are verbs ("Add flight", "Save changes"), titles are nouns.
- Keep one product name and accent across public, auth, home, detail, and
  settings; never let a rebrand drift between surfaces.
- Replace every starter string (the feed and profile labels, post and comment
  copy, the docs titles) with the product's own words; a starter phrase left
  in a footer, tab, or empty state ships as the product's copy.
