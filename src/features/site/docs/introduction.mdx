# Introduction

Welcome to **Takeout**, a production-ready starter template for building full-stack, cross-platform applications.

## What is Takeout?

Takeout is a comprehensive application starter built with modern tools and best practices. It provides:

- **Full-stack TypeScript** - Type-safe from database to UI
- **Cross-platform** - Web, iOS, and Android from a single codebase
- **Real-time sync** - Powered by Zero for instant data synchronization
- **Production-ready** - Authentication, database migrations, and deployment configs included

## Tech Stack

Takeout is built on a carefully selected stack of technologies:

- **One.js** - Universal React framework for web and native
- **Tamagui** - Universal design system and UI components
- **Zero** - Real-time sync and offline-first data layer
- **Drizzle ORM** - Type-safe database toolkit
- **SST** - Infrastructure as code for AWS deployment

## Project Structure

Takeout follows a feature-based organization:

```
takeout3/
├── app/                  # One.js routing
├── src/
│   ├── features/        # Feature modules
│   ├── interface/       # Shared UI components
│   └── server/          # Backend code
├── packages/            # Internal packages
└── scripts/             # Build and dev scripts
```
