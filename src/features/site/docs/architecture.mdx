## Overview

```
Clients (Web/iOS/Android)
    │
    │ local SQLite via Zero
    │
    ▼ WebSocket
Zero Server
    │
    ▼ postgres replication
PostgreSQL
```

No REST APIs for data. Clients have local databases that sync with the server.

## Stack

**One** - Universal React framework. File-based routing in `app/`, SSR/SSG for web, native nav on mobile.

**Zero** - Offline-first sync. Optimistic mutations, automatic conflict resolution, subscriptions that re-render on data changes.

**Tamagui** - Universal UI. Compile-time optimization, consistent styling, theme support.

**Better Auth** - Email, OAuth, passwordless. Sessions sync with Zero permissions.

## Structure

```
app/                # routes
├── (tabs)/         # native tab nav
├── (site)/         # marketing site
└── api/            # API routes

src/
├── features/       # feature modules
├── interface/      # shared components
├── data/           # Zero queries, mutations, models
│   ├── queries/    # read functions
│   └── models/     # schema + mutations
├── database/       # Drizzle schema
└── server/         # server utilities

scripts/            # tko CLI scripts
```

## Data flow

Queries:
```tsx
import { allPosts } from '~/data/queries/post'
const [posts] = useQuery(allPosts, { limit: 20 })
```

Mutations:
```tsx
await zero.mutate.post.insert({
  id: randomId(),
  content,
  createdAt: Date.now(),
})
```

UI updates instantly, syncs in background.

## Deployment

**SST** - AWS ECS + Aurora. Auto-scaling.

**Uncloud** - Any VPS with Docker. SSH deploy.

Both integrate with GitHub Actions CI/CD.
