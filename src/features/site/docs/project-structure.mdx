# Project Structure

This guide explains Takeout's directory structure and file organization, helping you navigate the codebase and understand where to find (and add) different types of code.

## Root Directory

```
takeout3/
├── app/                    # One.js routing
├── src/                    # Source code
├── packages/               # Internal packages
├── scripts/                # Build and deployment scripts
├── assets/                 # Static assets (fonts, images)
├── public/                 # Web static files
├── docs/                   # Documentation
├── .docker/                # Docker volumes (gitignored)
├── dist/                   # Build output (gitignored)
└── node_modules/           # Dependencies (gitignored)
```

## App Directory

The `app/` directory contains One.js routes using file-based routing:

```
app/
├── (tabs)/                 # Tab navigation group
│   ├── index.tsx           # Home tab (/)
│   ├── feed.tsx            # Feed tab (/feed)
│   └── profile.tsx         # Profile tab (/profile)
├── api/                    # API routes
│   ├── auth/               # Authentication endpoints
│   │   └── [...all].ts     # Better Auth catch-all
│   ├── zero/               # Zero sync endpoints
│   │   ├── pull.ts         # Query endpoint
│   │   └── push.ts         # Mutation endpoint
│   └── health.ts           # Health check endpoint
├── login.tsx               # Login page (/login)
├── settings.tsx            # Settings page (/settings)
└── _layout.tsx             # Root layout

```

### Routing Conventions

- **Files = Routes:** `app/about.tsx` → `/about`
- **Folders = Groups:** `app/(tabs)/` groups tab routes
- **API Routes:** `app/api/*.ts` become API endpoints
- **Dynamic Routes:** `app/post/[id].tsx` → `/post/:id`
- **Catch-all:** `app/[...slug].tsx` catches all unmatched routes

Named exports (not `export default`) enable better hot reloading.

### Feature Structure

Each feature follows this pattern:

```
feature-name/
├── components/             # React components
│   ├── FeatureComponent.tsx
│   └── index.ts            # Re-exports
├── server/                 # Server-only code
│   └── feature-logic.ts
├── hooks/                  # Custom hooks
│   └── useFeature.ts
├── queries.ts              # Zero queries
├── mutations.ts            # Zero mutations
├── types.ts                # TypeScript types
├── utils.ts                # Utility functions
└── index.ts                # Public API (exports)
```

### Schema Organization

**schema-public.ts** - Tables exposed to Zero sync:

```typescript
export const posts = pgTable('posts', {
  id: text('id').primaryKey(),
  title: text('title').notNull(),
  content: text('content'),
  userId: text('user_id').notNull(),
  createdAt: bigint('created_at', { mode: 'number' }).notNull(),
})
```

**schema-private.ts** - Server-only tables:

```typescript
export const analytics = pgTable('analytics', {
  id: serial('id').primaryKey(),
  event: text('event').notNull(),
  userId: text('user_id'),
  data: jsonb('data'),
  createdAt: timestamp('created_at').defaultNow(),
})
```

## File Naming Conventions

### Components

- **PascalCase:** `UserProfile.tsx`, `LoginForm.tsx`
- **One file per component:** Each component gets its own file
- **Index exports:** Use `index.ts` to re-export from directory

### Utilities

- **camelCase:** `randomId.ts`, `formatDate.ts`
- **Descriptive names:** Function name should match file name

### Types

- **PascalCase:** `User.ts`, `Post.ts`
- **Suffix for interfaces:** `UserInput.ts`, `ApiResponse.ts`

### Tests

- **Same name with suffix:** `UserProfile.test.tsx`, `formatDate.test.ts`
- **Co-located:** Tests live next to the code they test

## Import Patterns

### Absolute Imports (Preferred)

Use the `~` alias for imports from `src/`:

```typescript
import { Button } from '~/interface/Button'
import { useAuth } from '~/features/auth'
import { db } from '~/database/client'
```

### Relative Imports

Use relative imports within `packages/`:

```typescript
// Inside packages/helpers/
import { sleep } from './sleep'
import { randomId } from '../utils/randomId'
```

### Feature Exports

Import from feature index files:

```typescript
// Good
import { LoginForm, useAuth } from '~/features/auth'

// Avoid
import { LoginForm } from '~/features/auth/components/LoginForm'
import { useAuth } from '~/features/auth/hooks/useAuth'
```
